# Corrective Action Approval Policy

> Synthetic portfolio document. Replace with approved factory documents before any real deployment.

## 1. Human approval

**English:** Any action that creates, assigns, changes, or closes an operational task requires an authenticated human approval bound to the exact action and arguments.

**বাংলা:** অপারেশনাল টাস্ক তৈরি, বরাদ্দ, পরিবর্তন বা বন্ধ করার জন্য সঠিক অ্যাকশন ও আর্গুমেন্টের সঙ্গে যুক্ত প্রমাণীকৃত মানব অনুমোদন প্রয়োজন।

## 2. Idempotency

**English:** Repeated requests with the same idempotency key must return the original result and must not create a duplicate action.

**বাংলা:** একই আইডেমপোটেন্সি কী-সহ পুনরাবৃত্ত অনুরোধে মূল ফল ফেরত দিতে হবে এবং ডুপ্লিকেট অ্যাকশন তৈরি করা যাবে না।
