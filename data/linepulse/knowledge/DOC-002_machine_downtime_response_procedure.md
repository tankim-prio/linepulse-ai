# Machine Downtime Response Procedure

> Synthetic portfolio document. Replace with approved factory documents before any real deployment.

## 1. Immediate response

**English:** Stop the affected operation safely, isolate power where required, record the start time, and notify maintenance. Do not bypass machine guards.

**বাংলা:** প্রভাবিত অপারেশন নিরাপদভাবে বন্ধ করতে হবে, প্রয়োজন হলে বিদ্যুৎ বিচ্ছিন্ন করতে হবে, শুরুর সময় লিখতে হবে এবং মেইনটেন্যান্সকে জানাতে হবে। মেশিন গার্ড পাশ কাটানো যাবে না।

## 2. Escalation threshold

**English:** Escalate downtime above 30 minutes to the production manager and consider an approved operator or machine reassignment.

**বাংলা:** ডাউনটাইম ৩০ মিনিটের বেশি হলে প্রোডাকশন ম্যানেজারকে জানাতে হবে এবং অনুমোদিত অপারেটর বা মেশিন পুনর্বিন্যাস বিবেচনা করতে হবে।
